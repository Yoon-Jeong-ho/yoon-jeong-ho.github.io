# Jeongho Yoon Research Portfolio

This repository hosts a public GitHub Pages CV and research portfolio for Jeongho Yoon.

The site is a dependency-free static HTML/CSS/JavaScript project focused on:

- current academic affiliation and research availability
- selected publications with contribution summaries
- efficient reasoning and multimodal research directions
- education, engineering background, and public profiles

It keeps the public site limited to confirmed professional information. Source materials and
private documents remain outside the repository.

Traffic analytics use GoatCounter's hosted dashboard.
The public site does not display visitor counts directly.
There is no public owner or dashboard shortcut in the page URL.
For source tracking, share URLs with UTM tags such as:

- LinkedIn: `https://yoon-jeong-ho.github.io/?utm_source=linkedin&utm_medium=profile`
